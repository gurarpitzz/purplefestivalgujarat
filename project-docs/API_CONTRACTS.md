# API Contracts Reference — Purple Festival Gujarat 2027 (Phases 1–15)

**Document Status:** Authoritative REST & Page Route Contract Specification  
**Transport & Format:** JSON over HTTPS (`Content-Type: application/json; charset=utf-8`), extensionless Apache `.htaccess` routes (also directly addressable via `.php` script paths).  
**Security Envelopes:**
- **Authentication:** Cookie `pfg_session` (`HttpOnly`, `SameSite=Lax`, `Secure` under HTTPS) validated against `sessions.token_hash` (HMAC-SHA256).
- **CSRF Protection:** Header `X-CSRF-Token` (or body `csrfToken` / `_csrf`) required on all authenticated `POST`, `PATCH`, `PUT`, and `DELETE` endpoints via `requireCsrfToken()` **before** any DB write.
- **D-20 Mandatory Staff MFA Gate:** `SUPERADMIN` and `ADMIN` accounts without completed TOTP MFA (`mfa_enabled = 1` and session `mfa_verified = 1`) receive `HTTP 403` (`{"error": "Mandatory Multi-Factor Authentication (MFA) enrollment is required...", "mfaSetupRequired": true}`) on all protected admin and attendance APIs.

## 5. Provider Webhooks (`api/webhooks/*`)

| Endpoint | Method | Authentication | Request Headers & Payload | Behavior & Security Controls |
|---|---|---|---|---|
