# Implementation Master Roadmap — Purple Festival Gujarat 2027

**Architecture:** Native PHP 8.2 + MySQL 8.0 / MariaDB 10.4 (InnoDB `utf8mb4_unicode_ci`) + PDO + Vanilla JavaScript + HTML5 + CSS3  
**Hosting:** Bluehost Shared/cPanel Apache 2.4 + MySQL + Resend HTTPS API + cPanel Cron Jobs (**Zero Docker, Zero Containers, Zero Node Backend, Zero Redis/PostgreSQL**)  
**Local Dev & Testing Strategy:** Native Windows XAMPP (`C:\xampp` — `PHP 8.2.12`, `MariaDB 10.4.32`, `Apache 2.4.58`) with strictly isolated `pfg27_dev` and `pfg27_test` databases and a local file-based email sink (`MAIL_DRIVER=file` -> `tests/tmp/mail-sink/`), plus dev-only Playwright/Chromium browser & accessibility E2E verification.

## Mandatory Honesty & Verification Classification Key (§49–§50)

- **`VERIFIED WORKING LOCALLY`** — Implemented and verified via live automated tests on local native XAMPP (`PHP 8.2.12` + `MariaDB 10.4.32` + `Apache 2.4.58`) and headless Chromium Playwright E2E tests.
- **`PROVIDER SIMULATION VERIFIED`** — Verified locally against our deterministic Resend HTTPS protocol simulator and signed Svix HMAC-SHA256 webhook harness.
- **`CONFIGURATION BLOCKED`** — Code and CLI tooling are complete and verified locally, but live external execution awaits Project Owner credentials, `D-22` domain DNS (SPF/DKIM/DMARC), or authorized Bluehost cPanel deployment.
- **`CONFIGURABLE AND INACTIVE`** — Schema and configuration hooks exist with a safe default active (e.g., Free `₹0` Attendee registration under `D-05`), while optional paid/extended branches remain inactive until owner approval.
- **`DEFERRED WITH APPROVAL` / `MANAGED OUTSIDE WEBSITE`** — Intentionally deferred post-MVP or handled offline per §38 (`PHASE_16_CONDITIONAL_FEATURES_MATRIX.md`).
