## 3. Global Accessibility Toolbar & Sensory Adaptation Checks (All 10 Surfaces)

- [ ] **High Contrast (`data-contrast="high"`) & Yellow-on-Black (`data-contrast="yellow-black"`):** Verify zero FOUC on page reload (`includes/header.php` inline `<head>` script) and `>= 15:1` contrast across all cards, inputs, modals, and badges (`Status: Automated Chromium PASS; Manual AT/Firefox NOT RUN`).
- [ ] **Text Scaling (`100%`, `112%`, `125%`) & Browser Zoom (`200%` / `400%` at `1280×720`):** Verify zero horizontal scrolling and zero clipped controls at `320 CSS px` effective width (`Status: Automated 390px Chromium PASS; Manual 400% Firefox Zoom NOT RUN`).
- [ ] **Dyslexia-Friendly Typography (`data-font="dyslexia"`) & Reduced Motion (`data-motion="reduce"` / `prefers-reduced-motion: reduce`):** Verify smooth scrolling and decorative animations disable immediately (`Status: Automated Chromium PASS; Manual AT/Firefox NOT RUN`).
- [ ] **21 Specified Disabilities Accordion (`includes/disabilities-section.php` on `/accessibility`):** Verify `<h3><button type="button" aria-expanded="...">` structure announces as Level 3 Heading + Button in NVDA, JAWS, VoiceOver, and TalkBack (`Status: Automated DOM Audit PASS; Manual AT NOT RUN`).
